# 🤖 FreeAI-endpoint

Turn a free GitHub Codespace into a multi-model, OpenAI-compatible LLM API endpoint.

## 🚀 Quickstart

1. Click **Code** > **Codespaces** > **Create codespace on main**.
2. Run executable setup in the Codespace terminal:
   ```bash
   chmod +x setup.sh NewModels.sh DeleteModel.sh
   ./setup.sh
